## 详细任务分解

### 1. 项目结构创建
```
frontend/scripts/openapi-generator/
├── index.js               # 主入口脚本
├── config.js              # 配置管理
├── openapi-client.js      # OpenAPI文档获取与解析
├── code-generator.js      # 代码生成逻辑
├── templates/             # 代码模板
│   ├── api.js.template
│   ├── req.js.template
│   └── resp.js.template
└── utils/
    ├── file-utils.js      # 文件操作工具
    └── validation.js      # 数据验证工具
```

### 2. 核心模块实现要点

#### config.js
- 读取 `.openapirc.json` 配置文件
- 解析命令行参数（使用 minimist 或 yargs）
- 读取环境变量
- 提供默认配置
- 配置验证

#### openapi-client.js
- 使用 `node-fetch` 或 `axios` 获取文档
- 验证 OpenAPI 文档格式（基于 Spring Boot 3.2.0 + springdoc-openapi-starter-webmvc-ui 2.3.0，使用 OpenAPI 3.0 规范）
- 解析 paths、operations、parameters、responses
- 提取组件定义（components/schemas）
- 内存存储，不持久化

#### code-generator.js
- 按 tag 分组 API 接口
- 生成 API 调用函数（小驼峰命名）
- 生成请求参数对象（JSDoc 注释）
- 生成响应参数对象（JSDoc 注释）
- 使用模板引擎渲染代码

### 3. 测试策略
